# Fuentes de datos del proyecto

## Base de datos: Cohorte ERC

**Descripción:** Base de datos sintética de una cohorte prospectiva de 300 pacientes con enfermedad renal crónica (ERC) en estadios G2 a G4, seguidos durante 24 meses.

**Propósito:** Desarrollada para el Módulo II de Seminario de Epidemiología Clínica II, con el objetivo de practicar la limpieza de datos, análisis descriptivos, modelos de regresión y análisis de supervivencia.

## Características

- 300 participantes y 47 variables.
- Tres momentos de medición: basal, mes 12 y mes 24.
- Pérdidas de seguimiento y valores faltantes.
- Valores atípicos intencionales en creatinina y peso basal.
- Desenlace principal: progresión a estadio G5 o inicio de terapia de reemplazo renal.
